## 已修复问题及证据

| 问题 | 复现与影响 | 修复和验证 |
|---|---|---|
| 带年份片名误读类型词 | `The Truman Show 1998`、`The TV Set 2006`、`电影少女2018` 把名称中的类型词当作指令；噪声清理后的短名称还可能匹配另一作品 | 保留完整片名变体，采用上游名称证据，优先最长片名，仅解释片名外的类型指令；显式年份继续约束。测试覆盖发行标签、错误年份、候选顺序、额外 movie/film/TV 指令和后续短名称回退 |
| 空身份参数扩大查询 | `person?id=&q=…` 转按姓名、`detail?type=` 探测另一类型、`omdb?imdb=&title=…` 转按标题 | 客户端保留显式空参数，Worker 在上游请求前返回 400/no-store；测试断言零上游调用，真正省略类型的旧请求仍支持电影/剧集探测 |
| 展开列表仍截断资源 | 实际 Chrome 中 100 个分享只能访问前 50 个，来源列表另有 12 项上限 | 去掉渲染层额外限制，首屏仍各显示 6 项；浏览器验证展开 100 个分享及两组各 20 个来源，并复制第 100 个分享密码 |
| 详情重试丢失已加载资料 | 实际 Chrome 中点击重试后，Wiki 简介立即退回候选简介，已显示的补充评分消失 | 同一搜索、ID 和媒体类型保留活动视图模型；请求仍旋转代次并取消旧异步任务。验证等待、再次失败、同身份成功恢复，以及片名/年份/IMDb ID 改变后的清理和切换作品隔离 |
| 自动部署未保留 Dashboard 变量 | Workers Builds 默认执行 `npx wrangler deploy`，本机脚本的 `--keep-vars` 不会应用于该命令；Wrangler 默认配置为 false | 在 `wrangler.toml` 设置 `keep_vars=true`，严格 dry run 验证配置和两项限流 binding；仓库 `[vars]` 仍以代码为准，未读取或更改任何凭据值 |

搜索问题最初新增的 Worker 回归出现 4 项失败；资源与详情保留问题各由真实 Chrome 断言复现。修复后全部通过，并追加最长名称竞争、错误年份与恢复后的身份反例。浏览器冷启动另发现外部字体服务会拖延文档就绪，因此仅在隔离的模拟 API 回归中阻止 Google Fonts 网络请求，不更改产品字体行为。

## 其他审核结果

- 前端继续使用安全 URL 校验和 DOM 文本输出；异步结果受搜索和详情加载代次约束。资料保留不会跨新搜索或首页导航，作品纠正也不复用旧资源查询。
- Worker 保持 11/15 秒聚合预算、最多 6 次 TMDB 搜索与响应体大小限制。搜索评分每次基于缓存的上游原始数据重新计算，无需迁移资源/Wiki 缓存命名空间。
- 凭据仍只用于白名单同源只读路径，重定向不转发到其他提供方；公开错误不包含上游正文或密钥。限流、CORS、缓存隔离、登录过期及受限页面回归通过。
- 资源首次渲染仍最多 6 项，只有展开时增加 DOM；完整分享数量仍受 100 项上限约束。没有新增前端依赖或扩大首屏请求。
- `npm audit` 检查锁定依赖共 216 项，已知漏洞为 0。此结果是当日公告快照，不代表第三方服务始终可用。
