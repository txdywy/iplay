# 全面审核与优化 — 2026-10-13

基线为 `e948c98` / v1.0.13，本次修复版本为 **v1.0.14**。上轮四项问题全部修复；同路径交叉审核进一步修复海报异步回退、Wikipedia 改编身份与年份、旧资源响应密码置信度及评分兼容性。未确认新的 P0/P1；这不代表所有潜在缺陷都已被排除。

## 审核范围

- 前端全部 JavaScript、HTML/CSS：作品与人物身份、历史链接、请求取消、详情与补充数据竞态、渐进加载、恢复重试、移动/桌面布局、可访问状态。
- Worker 路由与共享设施：输入校验、上游超时/正文限制、缓存、执行上下文隔离、限流、来源路径与重定向、Cookie 白名单、错误与日志脱敏。
- 资源密码：页面配对、URL 与文本优先级、同级冲突、跨页及跨次重试、旧/新响应混用、扫描与显示上限、登录及权限变化。
- 依赖、锁文件、发布版本、ES Module 缓存标签、CI、GitHub Pages 与 Workers Builds，以及线上验收脚本。
- 前端与 Worker 分别修复后由独立只读审核交叉检查；新增行为先复现错误，再修复并保留回归。

## 修复与设计

| 问题 | 修复 | 主要证据 |
|---|---|---|
| HTTP 200 部分扫描覆盖旧资源 | 按来源和页面保存独立快照，成功替换、临时失败保留；成功搜索清理消失帖子，受限/过期登录清理旧分享 | 纯函数与 Chrome 验证来源交替失败、页面删除、展开状态和权限变化 |
| 旧片名提前扫描及详情重试复用旧查询 | TMDB 详情结束后调度扫描，失败时普通搜索可用候选降级；状态键含作品身份、名称和年份，响应核对发起时查询 | Chrome 延迟详情、提前滚动、规范名称校正及详情重试 |
| 详情海报被候选旧图覆盖、重绘废弃回退 | 优先采用有效详情主图；记录失败 URL、海报来源与待回退状态；同会话同图片复用 token | Chrome 验证主图更新、详情先/回退先两种时序及无迟到覆盖 |
| Wiki 片名题材词与数字误判 | 区分标题和显式消歧义后缀；描述/主导语校验自身类型与发行年份，剥离改编来源身份信息 | Node 与真实 workerd 验证小说/漫画/电视片名、数字片名、原著年份、电视电影、小说后缀及错年重拍 |
| 重试复活冲突密码 | 每页保留独立 rank/冲突证据；先比较已知 URL/文本优先级，再对照未知置信度的旧响应，冲突时隐藏密码 | 13 项资源状态测试，独立补充执行 38 个顺序矩阵场景；删除冲突来源后可恢复 |
| 评分依赖较新的 `Object.hasOwn` | 使用安全的 `hasOwnProperty.call`，继续忽略继承题材键 | 隔离 VM 移除 `Object.hasOwn` 后评分回归通过 |

资源逻辑提取到 `js/resources.js`，保留每页证据用于重新聚合，而非合并已经丢失置信度的展示结果。最多展示 100 个分享，达到上限后仍对已展示 URL 对账。Worker 资源缓存更新至 v11、Wiki 至 v4；新前端保守兼容缺少页面证据的旧响应。

## 构建与验收改进

- Tailwind 仅扫描生产 `index.html` 和 `js/`，避免测试/文档改变发布 CSS；生成文件由 CI 检查一致性。CSS 从基线 43,271 字节降至 42,166 字节；这是未压缩文件大小，不是加载耗时结论。
- 所有前端静态模块导入验证发布标签和实际目标文件，不再硬编码主模块的导入数量。
- `test:live` 动态发现 `js/` 下全部模块并逐字匹配实际发布资产；核心及可选 API 均检查 Worker 版本和 CORS。资源可选严格验收使用 `LIVE_REQUIRE_WPZY=1`。
- Node 覆盖率只统计实际加载的生产源码，排除测试辅助文件。`main.js` DOM 行为仍由真实浏览器回归验证，不能将 Node 汇总称为完整前端覆盖率。
- 部署说明统一为 `main` 的 Cloudflare Workers Builds 自动发布与 GitHub Pages 独立发布；本机 Wrangler 是故障回退。浏览器目标依据 Tailwind v4 要求，明确只有 Chrome 自动验证、其他浏览器仍需实机验证。
